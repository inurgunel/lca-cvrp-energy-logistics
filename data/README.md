# Data provenance

## What is in this directory

| File | Origin |
|---|---|
| `synthetic_dealers.csv` | Generated by `src/generate_synthetic_data.py` |
| `synthetic_facilities.csv` | Generated by `src/generate_synthetic_data.py` |
| `solved_routes.csv` | Produced by `src/cvrp_solver.py`, not versioned |

## Anonymization notice

**No file in this repository contains real operational data.**

The case study behind this repository used a distribution network whose dealer
locations, facility positions and delivery volumes are not redistributable and
are not published here, in any form, including aggregated or transformed form.

What is published instead is a generator that builds a network with the same
*structure*: the same count of dealers and facilities, a comparable clustered
spatial arrangement, and a demand distribution of similar shape. Coordinates
come from a seeded random process bounded by a coarse rectangle, and
identifiers are sequential integers. No point in `synthetic_dealers.csv`
corresponds to a real location, and no row corresponds to a real dealer.

## What this means for reproducibility

The **method** reproduces. Anyone can clone this repository, run the pipeline
and obtain internally consistent results.

The **published figures do not reproduce**, and are not meant to. The values
reported at YAEM 2026 belong to the case study network. Running this code will
produce different numbers, because it is a different network and because the
characterization factors in `src/config.py` are placeholders pending
substitution with the Ecoinvent 3.9 derived values used in the study.

Treating a synthetic run as if it validated the published result would be a
misrepresentation, so the distinction is stated here rather than left to be
inferred.

## If you want to run this on your own network

Replace the two CSV files with your own, keeping the column names:

**facilities**: `facility_id`, `latitude`, `longitude`

**dealers**: `dealer_id`, `assigned_facility`, `latitude`, `longitude`, `demand`

Then update the parameters in `src/config.py` to match your fleet, demand unit
and life-cycle inventory. Files matching `data/real_*` and
`data/*_confidential*` are excluded by `.gitignore` so that operational data
cannot be committed by accident.
